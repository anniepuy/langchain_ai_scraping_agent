## Project Overview

This project contains a simple LangChain Prompt Template that looks for a person's LinkedIn Profile.
It also contains a simple LangChain Agent that uses a React Agent from LangChain HUB to find a person's LinkedIn Profile.

## Technologies Used

Python
LangChain
LangChain HUB
Tavily API
